# IceGem Companion · Windows

晶光随行交互层：双晶片跟随、链接悬停点亮、按下聚光、释放折射、拖动收束、一次性待机高光。主指针仍由 Windows 绘制，位置和点击热点不变。

## 使用

先安装 IceGem 4.2 原生主题，再双击本目录 `Start.cmd`。托盘菜单可以暂停、切换轻柔/生动、开关跟随/点击、切换五色或退出。程序不自动开机启动，不修改原生光标方案；退出后装饰立即消失。

源码环境下首次启动使用 Windows 自带 .NET Framework 4.x x64 编译器生成程序；发行包已包含 EXE。偏好保存在 `%LOCALAPPDATA%\IceGem-Companion\settings.txt`。

## 行为

- 晶片按主体尾部停靠，32px 光标的停靠点相对热点为 (20,20)px；一大一下、一小一上，拖动时在约 120ms 内收束。
- 32px 下晶片主体高度约 11/9px，采用固定右倾约 19 度的中心对称菱形轮廓、四块宽渐变切面及细亮棱，统一抗锯齿边缘；取消硬像素双描边。每帧合成前重新读取热点，减少伴随层的位置滞后。
- 装饰跟随使用约 55ms 指数阻尼，主光标没有延迟；跟随偏离上限为光标画布宽度的 10%，快速移动也不与主体脱节。
- 点击按下聚光约 80ms，松开四芒折光约 240ms，闪光固定在松开位置。长按拖动不触发点击闪光。
- 文字、精确定位、缩放、移动、忙碌及无法识别的自绘光标隐藏伴随层。
- 静止 1.6 秒后只执行一次 650ms 晶片高光，随后取消刷新；系统关闭客户端动画时隐藏交互层。
- Raw Input 仅订阅鼠标；窗口不激活、不抓取、不拦截输入，不监听键盘。
- 角色通过当前标准光标句柄识别，自绘光标无法可靠识别时隐藏，而不是猜测为链接。

## 验证

```powershell
.\Build.ps1
.\IceGem-Companion.exe --self-test
.\IceGem-Companion.exe --smoke-test C:\path\smoke.txt
.\IceGem-Companion.exe --render-preview C:\path\frames
```

自测覆盖跟随收敛、闪光原点、拖动、文本隐藏、一次性待机及减少动态，并检查 32/48/64px 的紧凑停靠、最大拖离、实色切面像素及拖动过渡。冒烟检查创建自己的透明窗口，检查 Raw Input 注册、角色事件钩子、窗口样式与逐像素合成，不注入桌面输入。预览从同一运行时渲染器导出。

这些检查不等同于真实桌面交互验收；多屏混合 DPI、不同应用的自绘/抓取光标、全屏应用与会话切换仍需实机体验。当前交互层只提供 Windows x64；Linux 4.2 包包含原生动画，不包含交互程序。

晶片朝向以设计稿为准：上尖端偏左、下尖端偏右，左右尖端成对，不复用主指针的箭头轮廓。伴行一低一高，拖动时第二片沿外侧弧线进入右下短列，松开沿原路径散开；不随鼠标移动方向旋转。悬停提亮晶片棱线，并在主体右侧展开三道双面折光，离开后平滑消退；此效果独立于点击开关。按下晶片轻收束，拖动时取消收束。32/48/64px 的完整拖动过渡已检查晶片间距和排列方向。


已确认的 4.2 交互效果：拖动按轮廓间的可见空隙对齐，第一片日常停靠外移 2px；晶片主高光位于左上，阴影切面位于右下。悬停在主体右侧采用加长、加宽的三道双面折光，在系统光标变为链接小手时触发，离开后淡出。点击为 80ms 单圈聚光和 240ms 四芒闪光，保留明暗切面，不叠加厚阴影或大片光晕。拖动释放不播放点击闪光。

最新确认效果：悬停折光贴近主体右缘，避开两颗小晶片；点击保持单圈聚光与 240ms 四芒闪光，增强尺寸、切面宽度及对比。深浅背景预览由正式程序绘制，发行交付仅更新 dist 压缩包。
